Research and Projects

Learning-Based Visual Servoing for Robotic Manipulation (Aug 2025 - Present)
Research Assistant, Momentum Robotics Lab, CMU
Developing stereo vision-based visual servoing systems using dual-stream CNN architectures to predict 3D position offsets. Creating synthetic training data in Isaac Sim with dynamic rollout sequences and camera trajectory generation. Implementing weighted loss functions and data augmentation strategies for robust learning-based control of UR robotic arms through ROS integration.
Tech Stack: PyTorch, Isaac Sim, ROS, OpenCV, UR Robots

Dynamic Target Tracking Using Quadrotors
IIIT-Delhi Advanced Robotics Research Team
Implemented deep learning algorithms including Neural Circuit Policies (NCPs) to reduce training parameters by 90% while maintaining stability guarantees for target tracking. Developed end-to-end kinematic image-based visual servoing controllers for quadrotor control systems.
Tech Stack: Python, ROS, TensorFlow, OpenCV

Visual Odometry and Terrain Analysis for Lunar Navigation
NASA Moonranger Project
Optimized visual odometry systems for lunar terrain navigation. Developed terrain classification algorithms using point cloud data to identify ground, rocks, craters, and columns. Implemented both heuristic and learning-based approaches including PointNet++ for semantic segmentation of 3D point cloud data.
Tech Stack: Python, PointNet++, Point Cloud Processing

Visual SLAM for Autonomous Robots
Deployed a Direct Stereo Visual SLAM system for autonomous robot localization and mapping. Implemented bundle adjustment algorithms and debugged epipolar correspondence matching for stereo vision applications.
Tech Stack: ROS, Python, OpenCV, SLAM

Safe Reinforcement Learning with Lyapunov Methods
Developed BLAC (Barrier-Lyapunov Actor-Critic) and LAC (Lyapunov Actor-Critic) frameworks for safe control systems. Implemented comprehensive interpretability methods including constraint violation analysis and backup controller behavior tracking. Applied to unicycle navigation and simulated car following scenarios.
Tech Stack: Python, PyTorch, Control Theory

ML/DL Framework Benchmarking
Led a team to compare Python ML frameworks by implementing 7 different models and evaluating performance metrics across PyTorch and TensorFlow.
Tech Stack: Python, PyTorch, TensorFlow
